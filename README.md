# AccessIA - Prototipo de Asistencia Accesible

## Descripción del Proyecto
AccessIA es una aplicación móvil inclusiva diseñada para eliminar las barreras de comunicación y orientación en espacios públicos. El sistema integra inteligencia artificial para interpretar imágenes, reconocer textos y transcribir audio en tiempo real, adaptando su interfaz para usuarios con discapacidad visual y auditiva.

## Alineación con los ODS
Este proyecto fue desarrollado para abordar directamente los siguientes Objetivos de Desarrollo Sostenible de la ONU:
* **ODS 10 (Reducción de las Desigualdades):** Garantizando el acceso equitativo a la información en entornos públicos y comerciales.
* **ODS 11 (Ciudades y Comunidades Sostenibles):** Fomentando la autonomía de las personas con discapacidad en su tránsito y comunicación urbana.

## Stack Tecnológico
* **Frontend:** Flutter & Dart (Arquitectura modular, interfaces de alto contraste y compatibilidad con semántica nativa).
* **Backend/Microservicios:** Python.
* **IA y Procesamiento:** Google Gemini API (Visión y Procesamiento de Lenguaje Natural).

## Declaración de Uso de Inteligencia Artificial
En cumplimiento con las normativas del desafío universitario, declaramos el uso de las siguientes herramientas asistidas por IA:
* **Google Stitch:** Utilizado exclusivamente para la generación rápida de prototipos visuales y estructuración inicial de la interfaz de usuario.
* **Google Gemini API:** Motor principal para la transcripción bidireccional, limpieza de muletillas (Smart Replies) y análisis del entorno visual.
* *Nota: La lógica de integración, manejo de estado en Flutter y arquitectura del microservicio en Python son contribuciones originales del equipo de desarrollo.*
